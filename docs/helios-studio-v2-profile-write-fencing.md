# Packet 84: self-profile transaction fencing

The remaining-writer audit found that self-profile edits validate an earlier session/password snapshot and then update AdminUser directly. A workspace pause, membership revocation, session invalidation, account transfer or credential change can occur before that write. Security audit events are best-effort after commit and omit workspace ownership.

The route now hashes any new password before opening the transaction, acquires the common current workspace/account/membership guard, and rereads the account under that lock. The current email and password hash must still match the snapshot used for validation. The update includes the authenticated workspace predicate. Email/password changes append an owned security audit in the same transaction; audit failure rolls back profile fields, credentials and session-version changes. The existing validation, signedOut response, session revocation and ordinary-edit behavior remain intact. No real account or credential is modified.

Focused tests cover stale current authority, changed credential snapshot, audit ownership/rollback and normal-edit compatibility. Real Next/disposable PostgreSQL qualification covers fourteen observed waits across suspension, membership revocation, VIEWER demotion, session version, inactive account, workspace transfer and credential drift in both directions. Denied requests must preserve the independently changed account state and add no successful audit. An injected audit failure must roll back the credential update. Positive synthetic edits verify the actual password hash, old-session rejection, other-account isolation and owned audit. All original identity/membership fields, timestamps and synthetic credentials are restored.

Exact-head regression/TypeScript/Chromium, runtime, independent artifact hash/parse and matching merge tree remain integration gates. Other private writers, analytics, referral/public mutations, jobs/provider work, safety settlement, backlog and hosted compatibility remain open. Phase 1 OPEN; production ON HOLD.
