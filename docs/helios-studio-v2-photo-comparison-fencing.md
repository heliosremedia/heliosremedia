# Packet 74: Photo-comparison commit authority

Three actual-handler tests reproduce save-after-inspection failures: revoked editor authority, invalidated image registry authority, and a changed current image reference. The existing revision check alone does not establish these authorities. All three denial tests and the existing owned-save contract pass after the correction.

The save now requires current locked editor/session authority before mutation. It locks the owned page and its existing pairs, rechecks the page revision, and rereads the current sanitized page through the transaction connection. Image references must still match the inspected snapshot; direct pair/reference changes without a parent timestamp change return 409. Every standard/editorial/detail image receives locked registry owner/status validation inside the transaction. Provider inspection remains outside it. The existing upsert, pair replacement, revision response, validation and legacy-image behavior remain intact. Sole-workspace legacy fallback is evaluated under Workspace table protection.

Disposable runtime adds twenty observed races across both companies: revocation, demotion, invalidated session, quarantine of each of the three image positions, transferred asset, changed detail/pair reference, and changed revision. It checks foreign image and stale submission denial; single-winner concurrent initial creation and existing-page saves; injected pair insertion failure rolling back both page update and deleted pairs; inert stale retries; unchanged legacy references; and retained foreign content/registry. Strict synthetic image inspection has no network fallback.

Local 1,788 tests, TypeScript and scoped lint are the preparation gates. Published-head regression/Chromium, runtime artifact hash/parse and unchanged schema/index/access postflight remain required before integration. This does not establish hosted object delivery, full Helios compatibility or whole Phase 1 exit. No schema migration, provider deletion, credentials or production operation. Production ON HOLD.
